# Own Agent Workspace behind one Runtime

Agent Workspace will own its complete Product View and consume Jarvis authority through one deep Agent Workspace Runtime Interface with production and in-memory Adapters. The Runtime projects immutable navigation, Timeline, Decision, Compact Execution Row, Artifact, asset, and Composer state and maps Product intents back to native commands; Agent Workspace will no longer embed or restyle native Chat or Asset Center presentation. Professional Workspace remains upstream-native and exposes only the minimal Workspace Integration Seam for reciprocal navigation and authoritative context preservation. A project-owned DESIGN.md derived exclusively from Porsche Design System v4 light-theme principles governs Agent Workspace, while Professional Workspace remains outside that visual system. This supersedes ADR-0012's decision to retain a wrapped native Chat controller as the Product Timeline implementation.
