# Keep vertical design dialogue inside native Skills

This decision supersedes only ADR-0014's mandatory strategy-card dialogue and confirmation; its single-mainline and packaged-vertical decisions remain accepted.

Watch and Tablet remain deep native Skill Packages behind Jarvis's existing Skill seam: each Skill applies professional defaults, uses the unchanged `ask_user` only for a material decision the Agent cannot safely infer, treats an explicit Artifact request as generation authorization, and supplies the rules for one concise actual-image review through the existing Critic. This replaces fixed strategy cards, confirmation text, and Product View decision programs with Agent-led conversation while adding no Tool, schema, state model, Adapter, retry loop, or vertical UI; rejected images remain visible for professional discussion and are never regenerated automatically.
