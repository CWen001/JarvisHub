# Use the complete native Canvas as the Professional Workspace

The Agent Workspace (the user-facing Product Chat Shell) is the default experience, while an explicit user action reveals the complete native Jarvis Canvas with Chat and the current Flow context preserved. Professional Workspace exposes a reciprocal Agent Workspace action. The two are visually isolated surfaces: Professional Canvas and header components are not rendered beneath Agent Workspace, and switching closes workspace-specific transient panels while preserving authoritative Project, Flow, Session, and node state.

The product will not build a Mini Canvas or a second Artifact editor. Professional Workspace is a distinct product capability and may later be entitlement- or payment-gated, but this boundary must not duplicate Jarvis execution or persistence. This accepts the native Canvas's complexity in advanced use in exchange for retaining its authoritative node, graph, editing, asset, and execution behavior without duplication.
