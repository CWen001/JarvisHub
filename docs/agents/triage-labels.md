# Triage labels

Use the following canonical triage-role mapping:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not fix | `wontfix` |

Engineering skills should use these exact label strings. Reuse existing labels when present and create a missing label only when the workflow requires it.
