# India Batch 10 — Peacock Process + Innovation Budget

## Schema questions
1. Do named appearance-driving processes produce more specific, credible visual results than generic finish adjectives?
2. Can a default `restrained-progressive` innovation budget create four visibly different proposals while preserving a mature 2026 baseline?

## Fixed
- four independent India-oriented upper-mainstream phones
- about 80% Functional Form / 20% restrained Peacock-derived Cultural Expression
- each phone keeps the complete 2026 baseline but receives exactly one clear Leading Departure
- each direction names one hero process, substrate, physical zone, visible signature, scale and boundary behavior
- no literal peacock, feather illustration, eye motif, bird silhouette, jewel pastiche or rainbow finish

## Four strategies
1. **PVD camera spine** — camera-architecture departure; selective gradient PVD on rigid metal carrier
2. **IMT depth field** — rear-architecture departure; in-mould decorative film under clear hardcoat
3. **Laser microprism rail** — frame-and-controls departure; laser-structured directional microtexture
4. **NCVM floating court** — appearance-process departure; bounded non-conductive vacuum metallisation on a rigid camera court

## Promotion rule
Retain innovation-budget fields only if differences are visible at thumbnail size without causing multiple competing novelties. Retain process fields only when rendered appearance corresponds to the named process and a credible physical zone.
